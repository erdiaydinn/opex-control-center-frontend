V26.1 WINDOWS POWERSHELL UYUMLULUK DÜZELTMESİ (04.08.2026)
- Docker Compose etiketleri Go template yerine JSON üzerinden okunur.
- Windows PowerShell 5'te oluşan "function com not defined" hatası giderildi.
- Etiket sonucu boş olduğunda null değer üzerinde Trim çağrısı yapılmaz.
- Mevcut Compose projesi veya .env bulunamazsa yeni/boş proje oluşturulmaz.

Bu sürüm, kaybolan platform kartlarını V25 birleşik kaynak üzerinden geri getirir:

- Hiring Control / İşe alım talebi
- Inventory / Sayım ve envanter

Access Control düzeltmeleri:
- Dokuz platformun tamamı yetki tablosunda görünür.
- Inventory, Academy, AI Insight ve Access Control için eksik detay yetkileri eklendi.
- View, Admin, ekran, aksiyon ve veri kapsamı alanları korunur.
- V4 yetki kayıtları V5 kataloğuna kayıpsız taşınır.
- "Modülleri Yenile" yalnız eksik platform/alanları ekler; mevcut seçimleri silmez.
- Kullanıcıdan kaldırılan bir grup kaydetme sırasında kendiliğinden geri eklenmez.
- 125% tarayıcı yakınlaştırmasında üç kolonun çakışmaması için grid daraltıldı.
- Daha dar ekranlarda detay paneli alt satıra geçer; alanlar kaybolmaz.

Kurulum / güncelleme:
1. ZIP'i klasöre çıkartın.
2. Docker Desktop açıkken PowerShell'de klasöre geçin.
3. Set-ExecutionPolicy -Scope Process Bypass -Force
4. .\UPDATE_OPEX_UNIFIED_V26.ps1

Script mevcut Compose proje adını ve .env ayarını bulmaya çalışır, aynı Docker
volume'larını kullanır ve volume silmez. Sağlık kontrolü tamamlanmadan başarı
mesajı göstermez.

Doğrulama:
