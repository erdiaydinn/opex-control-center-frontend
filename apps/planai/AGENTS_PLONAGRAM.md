# AGENTS — PLONAGRAM OS

## Prime directive

Do not optimize appearance before physical correctness.

## Required workflow

Specification → Fixture/Test Data → Engine Logic → Evaluation → Trace → UI → 3D Mirror.

## Release discipline

Every patch must state:

- Problem
- Evidence
- Scope
- Changed files
- Not touched
- Tests
- Security impact
- Rollback
- Expected output

## Hard rules

- No Store DNA = no production planogram.
- No embedded catalog = no production planogram.
- No ABC = no store-specific planogram.
- No physical fit = no placement.
- No storage match = no placement.
- No unplaced report = no engine trust.
- No decision trace = no release.
- No speculative patch.
