PLONAGRAM CHANGE FILES V3.2

Bu paket V3.1 üzerine düzeltmedir.

Eklenenler:
- Loading klasörü dolu kalır.
- 2D Planogram referans görseldeki raf/modül operasyon ekranına yaklaştırıldı.
- Modül aksiyonları: + Raf, Modül ölçü, Modül kuralı, Yazdır, Modül sil.
- Raf aksiyonları: Raf düzenle, Raf ölçü, Raf kuralı, Raf yazdır, Ürün ekle, Raf sil.
- Ürün listeleme, facing artır/azalt ve ürünü raftan çıkarma eklendi.
- Sağ detay paneli ve AI ek öneriler eklendi.
- 3D sahnede rafa/modüle tıklayınca 2D Planogram ekranında ilgili modül/raf açılır.

Kurulum:
1) frontend klasöründe yedek al.
2) ZIP içindeki src klasörünü frontend/src üzerine kopyala.
3) npm run dev
4) CTRL + F5
