
PLONAGRAM REBORN FUNCTIONAL BRIGHT UI V5

Bu sürüm önceki karanlık/amatör 3D görünümü ve eski yama hissini kaldırmak için tek temiz App.css + App.jsx üzerinden çalışır.

Ne değişti:
- 3D ekran aydınlık, okunabilir, kullanıcı dostu hale getirildi.
- Logo F gibi değil, P monogram olarak yeniden çizildi.
- TR/EN/DE/AR dil butonları gerçek state ile çalışır.
- Mimari düzenleyicide modül/kolon/soğuk oda/donuk oda seçilir ve X/Y/W/H gerçekten değişir.
- AI en iyi yerleşimi öner butonu layout'u gerçekten yeniden dizer.
- Kurallar ekranı sade ve global kullanıcının anlayacağı dille düzenlendi.
- Eski component importları yok; ham HTML fallback yok.

Kurulum:
1) frontend klasöründe src klasörünü yedekle.
2) Bu zip içindeki src klasörünü frontend/src üzerine yaz.
3) npm run dev
4) Tarayıcıda CTRL+F5 yap.
