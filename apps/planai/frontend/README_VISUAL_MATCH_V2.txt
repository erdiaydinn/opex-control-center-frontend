PLONAGRAM OS VISUAL MATCH V2

Kurulum:
1) frontend klasöründe yedek al:
   xcopy src src_backup_visual_match_v2 /E /I /Y

2) ZIP içindeki src klasörünü frontend/src üzerine kopyala.

3) Çalıştır:
   npm run dev

4) Tarayıcı:
   CTRL + F5

Not:
Bu paket, gerçek WebGL rebuild değil; görsel eşleşme paketidir.
CSS ile çizilen zayıf 2.5D sahneyi, onaylanan premium Digital Twin referans sahnesiyle değiştirir.
Bir sonraki gerçek adım: Live3D'yi React Three Fiber ile yeniden kurmak.
