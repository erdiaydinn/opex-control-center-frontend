# PLONAGRAM Loading

Bu klasör artık boş değil. Premium çizgisel PLONAGRAM loading component'i burada:

- `PremiumLoading.jsx`
- `PremiumLoading.css`

Mevcut `App.jsx` içinde ayrıca inline `LoadingSplash` fonksiyonu olduğu için proje importsuz da çalışır. İstersen ileride App.jsx içinde `LoadingSplash` yerine bu component import edilerek kullanılabilir.
